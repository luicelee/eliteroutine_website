# 엘리트 루틴 케어 — 제품 홈페이지

초·중·고 유소년 엘리트 선수(38개 종목)와 학부모를 위한 루틴·부상·진학 관리 앱
**엘리트 루틴 케어**의 제품 홈페이지입니다.

> 다치지 않고, 기록이 남고, 진학까지.

- 단일 `index.html` — 바닐라 JS/CSS, 외부 의존성 없음
- GitHub Pages로 배포
- 다크(기본)/라이트 2테마, 인터랙티브 데모 4종 내장

## 로컬 확인

```
python -m http.server 8000
# → http://localhost:8000
```
